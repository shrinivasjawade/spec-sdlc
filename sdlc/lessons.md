# Lessons learned

The learning loop: when the same correction, bug class, or incident shows up twice,
record it here — then **promote** recurring ones into an enforceable place:
- a project convention that must always hold → a pattern in [`patterns.md`](./patterns.md) (`PAT-*`)
- something the agent should always know → `CLAUDE.md` ("Things the agent gets wrong")
- a behaviour that must be proven → a new acceptance criterion + test in the spec

Keep each lesson specific and testable. A lesson that stays here more than twice
without being promoted is a sign it isn't being enforced.
