How to read this

Colours tell you where things stand at a glance.

  • Done — finished and approved
  • Active — happening now
  • Pending — not started yet
  • Blocked — needs a fix before moving on
  • Gate — a human approves before the pipeline continues

Why it's built this way

The spec is the single source of truth. Nothing gets built or tested that isn't written as a numbered, testable rule first.

Every rule is traced to a task and a test, so coverage is provable — not a guess.

An independent reviewer checks the work with fresh eyes, and a human always ships — the agent never pushes or deploys on its own.
